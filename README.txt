ABHIMANYU BIRTHDAY SURPRISE WEBSITE
===================================

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Firefox.
3. Everything works locally; no internet is required.

Included:
- index.html
- style.css
- script.js
- assets/hero_abhi.png
- assets/best_friend.png
- assets/memories.png
- assets/gift.png
- assets/note.png

Customization:
- Change birthday message/text directly in index.html.
- The popup message is inside script.js in the variable named "message".
- If you want to use your real photos, replace any PNG inside assets/ with your own image using the same filename.

Vibe:
Close-friend / best-friend birthday page, affectionate but not romantic.
